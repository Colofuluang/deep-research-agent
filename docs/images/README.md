# 项目运行截图

本目录保存项目实际运行截图，根目录 README 已引用以下四张图片。更新界面后可直接替换同名文件。

| 文件名 | 建议内容 |
| --- | --- |
| workspace.png | 研究工作台整体页面 |
| progress.png | 有真实进度日志的执行中页面 |
| report.png | 最终报告，优先展示标题、结论和来源标记 |
| resume.png | 中断提示或按编号恢复后的页面 |

图片引用路径以根目录 README 为基准。

只使用当前程序的真实截图。截图前检查页面和终端，收起 API 密钥、访问令牌及无关个人内容；不要把尚未实现的视觉稿作为已完成界面展示。
